# DM-Care prototype test checklist

Use fictional/demo information only.

## Core functions
- [ ] App opens on phone, tablet, and desktop widths.
- [ ] Arabic/English toggle changes language and text direction correctly.
- [ ] Dashboard navigation opens each section.
- [ ] Add fasting glucose reading and confirm it appears in history.
- [ ] Add post-meal and random readings.
- [ ] Delete a demo reading and verify the list updates.
- [ ] CSV export downloads the displayed readings.
- [ ] Add and remove a medication/insulin reminder entry.
- [ ] Add and remove a symptom/event entry.
- [ ] Refresh the page and confirm demo data persists in the same browser.
- [ ] Clear demo data and confirm it is removed.

## Usability and accessibility
- [ ] Labels are understandable in both languages.
- [ ] Buttons and inputs are usable by touch.
- [ ] Text contrast and font sizes are readable.
- [ ] No horizontal overflow on mobile.
- [ ] Keyboard focus is visible when using a keyboard.

## Safety and reliability
- [ ] Confirm the app does not calculate insulin doses or recommend changing treatment.
- [ ] Confirm reminder entries reflect the user's clinician-provided instructions only.
- [ ] Confirm all testing uses fictional data.
- [ ] Capture genuine screenshots of the running app for the project report.
- [ ] Record device/browser, test date, observed result, and any issue for each test.
